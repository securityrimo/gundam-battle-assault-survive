# 기동전사 건담 어설트 서바이브 (Gundam Assault Survive) 한국어 패치

- **패치 파일**: `GAS_KR_v1.1.xdelta` (약 4.1MB)
- **버전**: v1.1 (2026-07-26)
- **대상 게임**: Gundam Assault Survive (J) — 반다이남코, 디스크 ID ULJS-00281, PSP
  - ※ 같은 엔진 계열의 전작 「건담 배틀 유니버스」와는 별개 패치입니다.

## v1.1 변경점

- **미션 진행불가 문제 수정** — 일부 미션에서 에어리어 전환이 일어나지 않아 진행할 수 없던 문제를 수정했습니다.
  게임 엔진이 캐릭터 이름 문자열을 내부 오브젝트 식별에 사용하는 것이 원인으로, 해당 이름을 원문으로 되돌렸습니다.
- **결과화면(BATTLE RESULT) 라벨 한글화** — 보너스·집계 라벨과 스탯 라벨을 한글로 다시 그렸습니다.
- **캐릭터·파일럿 고유명은 원문(일본어) 유지** — 위 진행 안정성 확보를 위한 조치입니다.
  MS·기체·오브젝트 이름, 계급, 프롤로그 등 그 외 텍스트는 한국어로 표시됩니다.

> v1.0에는 위 진행불가 문제가 있어 v1.1 사용을 권장합니다.

## 적용 방법

1. 원본 일본판 ISO를 준비합니다.
   - 파일: `Gundam Assault Survive (Japan).iso` (854,491,136 bytes)
   - SHA-256: `2CA94945B4E72CADA3B79CD92954704DE6B43326A734116053BC572834039664`
2. xdelta3(또는 xdeltaUI 등 GUI 툴)로 패치를 적용합니다.
   ```
   xdelta3 -d -s "Gundam Assault Survive (Japan).iso" GAS_KR_v1.1.xdelta "Gundam Assault Survive (Korean).iso"
   ```
3. 적용 결과 확인 (선택):
   - 한국어판 SHA-256: `36FFCF6B1A7E4A6EA07E0CAF0409FD124AFD3F11D88EFE14AD23C8A352349AB3`

## 미번역 항목 (알려진 한계)

- **이름 입력 화면**: 원문이 가나→SJIS 저장 방식이라 한글 입력이 불가하여,
  입력 안내문과 `声` 등 일부 버튼은 일본어로 유지됩니다. (시스템 사양상 제약)
- **VS 배틀 일부 보조 이미지 문자**: 대기 / 준비 완료 / 출격 불가 등 `taisen_04·07` 계열 이미지 글자는
  이번 범위에서 제외했으며 후속 버전에서 대응 예정입니다.
- **캐릭터·파일럿 고유명**: 게임 엔진이 이 이름 문자열을 미션 내부 오브젝트 식별에 사용하여,
  한글화 시 일부 미션이 진행되지 않습니다. 진행 안정성을 위해 원문(일본어)으로 유지합니다.
  (MS·기체·오브젝트 이름, 계급 등은 한국어로 표시됩니다.)
- **영문 UI · 로마자 표기**: MS / BGM / PLAYER 등은 원문을 그대로 유지합니다. (디자인)
- **저빈도 화면·조합 라벨**: 자간·줄바꿈은 제보되는 대로 후속 버전에서 다듬을 예정입니다.

## 주의

- **구형 PPSSPP 세이브 스테이트(`.ppst`)** 를 불러오면 EBOOT RAM이 복원되어 일부 텍스트가
  옛 상태(일본어)로 보일 수 있습니다. 세이브 스테이트 없이 새로 부팅해 확인해 주세요.
- 세이브 데이터에는 저장 시점의 한글 도너 배정이 기록됩니다. 향후 버전에서도 도너 매핑을
  유지하므로 기존 세이브와 호환됩니다.
